# Navigation Bar (HTML & CSS)

## Overview
This project is a simple responsive navigation bar built using HTML and CSS.  
It demonstrates how to create a clean, modern menu for websites.


## Features
- Responsive navigation bar
- Hover effects on menu items
- Clean and minimal design
- Easy to customize colors and layout

## Technologies Used
- HTML5
- CSS3
